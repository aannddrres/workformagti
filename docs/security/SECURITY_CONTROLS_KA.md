## 1. შემავალი მონაცემების ვალიდაცია (V2.1.1)

მოთხოვნის სტრუქტურა აღწერილია
[`docs/api-contract/openapi.json`](../api-contract/openapi.json)-ში. სერვერზე
ვალიდაცია ოთხ ფენად მიდის. თითოეული ფენა შეცდომისას პასუხობს 400-ით და
მიღებულ მნიშვნელობას პასუხში არ იმეორებს (`web/GlobalExceptionHandler.java`).

1. **ტიპი.** JSON-ის სხეულს Jackson ტიპიზებულ record-ებში აბამს: `Long`,
   `OffsetDateTime`, enum. path- და query-პარამეტრებს Spring აბამს.
   შეუსაბამო ტიპი 400-ია.
2. **ერთი მნიშვნელობა.** პარამეტრი, რომელსაც handler ერთ მნიშვნელობად იღებს,
   ორჯერ თუ მოვიდა, მოთხოვნა უარიყოფა. ასევე უარიყოფა, როცა ერთი და იგივე
   პარამეტრი query-შიც მოდის და form-ის სხეულშიც
   (`web/RepeatedParameterGuard.java`).
3. **Bean Validation** request record-ებზე: `@NotBlank`, `@NotNull`,
   `@NotEmpty`, `@Email`, `@Size`, `@Pattern`.
4. **ბიზნეს-წესი** შესაბამის service-ში (თავი 2).

## 2. ერთად შემოწმებადი მონაცემები (V2.1.2)

ეს წესები ერთ ველს კი არ ამოწმებს, არამედ ველების ერთობლიობას. თითოეულს
თავისი owner decision ან კოდის ერთადერთი წყარო აქვს:

- **`status` და `is_draft` ორი სხვადასხვა ღერძია.** `is_draft` პირადი
  ავტოშენახვაა და მასალას ყველასგან მალავს ავტორის გარდა, კონტენტ-ადმინის
  ჩათვლით (PO-34). სარედაქციო მდგომარეობა `status`-ში ინახება
  (`article/ArticleVisibility.java`).
- **დაგეგმილი გამოქვეყნება.** `published` სტატიის ხილვადობა
  `published_at`-ზეც არის დამოკიდებული. წესი ორ ადგილას წერია: Java-ში და
  Angular-ში (`shared/article-visibility.ts`). ორივეს ერთი და იგივე
  შემთხვევები ამოწმებს: `docs/api-contract/article-visibility-cases.json`.
- **აუდიტორია.** სტატიას მინიმუმ ერთი სამიზნე დეპარტამენტი სჭირდება
  (`@NotEmpty`). `All` ყველას ნიშნავს; ქვეჯგუფი მშობელ დეპარტამენტს prefix-ით ეკუთვნის
  (`util/DepartmentMatcher.java`, `security/ManagerScope.java`). უცნობი
  დეპარტამენტი კარს არ კეტავს (PO-23).
- **დანართი მიჰყვება მასალის აუდიტორიას** (PO-19/DEC-P01, PO-36;
  `storage/FileAccessPolicy.java`).
- **ქვიზის მცდელობა** მიბმულია სტატიის ვერსიაზე: მცდელობის ნომერი
  უნიკალურია წყვილზე (მომხმარებელი, სტატია, ვერსია) (V51).
- **წაკითხვის დადასტურება:** პირველი დადასტურება უცვლელია (PO-30).
  კონტენტის წაშლა მტკიცებულებას არ შლის (PO-18).
- **დაარქივებული სიახლე** ოპერატორს პირდაპირი ბმულითაც ემალება (PO-35).
