# Magti Portal — IT questionnaire site

დამოუკიდებელი, ერთფაილიანი კითხვარის საიტი IT კოორდინატორისა და შესაბამისი
ტექნიკური გუნდებისთვის.

## გაშვება

გახსენით `index.html` პირდაპირ ბრაუზერში, ან ამ დირექტორიაში გაუშვით ნებისმიერი
სტატიკური HTTP server.

საიტს არ სჭირდება backend, build ან dependency. პასუხები ინახება მხოლოდ იმ
ბრაუზერის `localStorage`-ში, რომელშიც ფორმა ივსება. გაზიარებისას იქმნება
ადამიანისთვის წაკითხვადი Markdown ფაილი.

## ფუნქციები

- 12 თემატური IT მოთხოვნა;
- პასუხის ხუთნაწილიანი საერთო ფორმატი;
- ავტომატური ლოკალური შენახვა;
- პროგრესის მაჩვენებელი;
- Web Share მხარდაჭერა, სადაც ბრაუზერი იძლევა;
- Markdown ჩამოტვირთვა და clipboard copy;
- ბეჭდვა ან PDF-ად შენახვა;
- desktop, tablet და mobile განლაგება.

## უსაფრთხოება

ფორმაში არ უნდა ჩაიწეროს პაროლი, token, secret, private key ან wallet password.
საიტი არ აგზავნის მონაცემებს არცერთ სერვერზე.
